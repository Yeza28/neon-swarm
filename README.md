**Neon Swarm** is an original neon arena survival shooter for the desktop browser. You are the last bright ship in a dark arena: fly with WASD, aim with the mouse, dash through danger, chain kills to raise a ×9 combo multiplier, grab spread and rapid power-ups, and every fifth wave bring down the Dreadnought — a hex-hulled boss that answers with bullet rings, aimed spreads, spirals and summoned minions. Plain static files, no libraries, no network: everything, including the synthesised sound, is generated by the code in this repository.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 in a desktop browser. (Node 22.18 or later; there is nothing to install.)

To hand the game in the way the bounty does, run the entrypoint, which copies `game/` and `screenshots/` to the output directory and writes its `dossier.json`:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## How to play

- **WASD / arrow keys** — fly · **mouse** — aim · **hold click / Space** — fire
- **Shift / right-click** — dash (brief invulnerability, 1.5 s cooldown)
- **P / Esc** — pause · **M** — mute
- Kills within 2.6 s of each other build the combo: every 7 chained kills raises the score multiplier, up to ×9. Taking a hit resets it.
- Power-ups drop from wrecks: **S** spread cannon and **R** rapid blaster (three levels each, 18 s), **O** shield (absorbs one hit), **+** hull repair.
- Four foe classes — chasers, weavers, splitters that burst into minis, and stingers that circle then lunge — plus the Dreadnought on every fifth wave.

## Layout

- `main.ts` — the entrypoint the grader runs (Node 22): hands in `game/` and `screenshots/` with the vendored dossier library.
- `game/` — the playable game as static files: `index.html` and ES modules under `src/` (`world.js` is the whole simulation, `render.js` the canvas art — the nebula, grid and arena wall are pre-rendered once into a backdrop so a frame is one blit plus the moving pieces — `audio.js` the Web Audio synth, `input.js`, `shots.js`, `main.js`).
- `screenshots/` — the four entry screenshots, staged deterministically by `game/src/shots.js` (`?shot=start|play|boss|end&seed=N`, see `shots.json`): the action scene replays a seeded run to its busiest swarm moment and the boss scene frames the Dreadnought duel mid-fight.
- `tests/world.test.mjs` — headless checks of the simulation: `node tests/world.test.mjs`.
- `vendor/makefun-game.ts` — make.fun's dossier library, vendored unchanged.
